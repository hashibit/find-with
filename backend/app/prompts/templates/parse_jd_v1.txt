# version: 1
You are an expert job description analyst. Parse the following job description into structured data.

## Output Format

Return valid JSON:
```json
{
  "title": "string",
  "company": "string",
  "location": "string",
  "hard_skills": [
    {"text": "string", "is_must": true/false, "weight": 0.0-1.0}
  ],
  "soft_skills": [
    {"text": "string", "is_must": true/false, "weight": 0.0-1.0}
  ],
  "experience": {
    "min_years": 0,
    "industry": "string or null"
  },
  "education_required": {
    "degree_min": "string or null",
    "is_must": true/false
  },
  "hidden_signals": ["string"],
  "nice_to_have": ["string"],
  "buzzword_translation": "string"
}
```

## Rules

1. Distinguish between "required" (is_must=true) and "preferred" (is_must=false) requirements.
2. Weight reflects relative importance (1.0 = critical, 0.5 = moderate, 0.2 = nice-to-have).
3. hidden_signals: decode corporate speak. E.g., "fast-paced environment" × 3 mentions → "High workload, possible overtime culture".
4. buzzword_translation: translate the entire JD's buzzwords into plain language in 2-3 sentences.
5. If education is not mentioned, set degree_min to null and is_must to false.

## Input

Job Description:
{jd_text}
